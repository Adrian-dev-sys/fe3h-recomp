# Contributing

This is a personal fork of [LAS Recomp](https://github.com/peiikai/LASRecomp) for *Fire Emblem: Three Houses*,
shared as-is. Issues and pull requests about running *Three Houses* are welcome here; anything about LAS Recomp
itself or *Link's Awakening* belongs [upstream](https://github.com/peiikai/LASRecomp).

## The one hard rule: no Nintendo files

Nothing owned by Nintendo may ever be committed or attached to an issue or pull request:

- no copies of the game in any form, and no DLC
- no extracted game files (`extracted/`), no generated code (`generated/`), no fonts
- no game assets of any kind: textures, models, music, movies, text, level files
- no logs, dumps or captures that contain recompiled game code or shader sources made from it

Screenshots and short clips of the game in bug reports are fine.

## Reporting a problem

Use the bug report form: it asks for your hardware, what happened, and `fe3hrecomp.log` from the program's folder
(the session that just ended; attach it before playing again). Questions go in Discussions.
